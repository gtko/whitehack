## 🎯 What is the Negative Billing Option?

The **Negative Billing Option** (also called "negative option feature" or "trial-to-subscription dark pattern") is a business model where:

1. A consumer signs up for a **low-cost trial** ($0.50–$3)
2. The trial **silently converts** to a full-price recurring subscription ($27–$55/month)
3. **No confirmation email** is sent about the subscription
4. Cancellation is deliberately **difficult** (multi-step, requires email + card digits)
5. A **no-refund policy** is enforced, often with **class-action waivers**

> *"Ad → Quiz → Trial → Subscription (web-to-web)"* — Ruby Labs job listing

This model generates **massive complaint volumes** on Trustpilot, Signal-Arnaques, BBB, and consumer forums worldwide.
